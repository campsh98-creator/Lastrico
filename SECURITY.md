# Sicurezza

Non pubblicare vulnerabilità, credenziali, token, dati personali o dettagli di localizzazione sensibili nelle issue.

Per una vulnerabilità:

1. usa una segnalazione privata GitHub Security Advisory del repository; se il repository
   non è ancora pubblico, contatta privatamente il maintainer tramite
   [il suo profilo GitHub](https://github.com/campsh98-creator);
2. descrivi impatto, riproduzione e versione interessata;
3. attendi una conferma prima di divulgarla pubblicamente.

La beta usa servizi cartografici esterni e non deve essere considerata un sistema di navigazione di sicurezza o emergenza.
