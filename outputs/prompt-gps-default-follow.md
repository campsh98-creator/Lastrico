# Foreground GPS by default - execution contract

Scope: isolated codex/gps-default-follow branch from current main; PR only. No merge, deployment, production pilot or preview changes, remote secrets or Traffic calls.

Acceptance: on launch one foreground geolocation watch starts only when the browser reports granted permission and the user has not explicitly stopped GPS. Prompt/unknown/denied permissions never cause automatic geolocation calls. An existing GPS/recenter/Start gesture can enable tracking. Use one watcher for planner position and navigation, preserving navigation fix processing, anti-pave routing, rerouting, voice and opt-in trace recording. Never overwrite planner endpoints automatically. Initially center the map once; user pan/zoom/rotate (even before first fix) suspends follow; existing recenter resumes it. Expose honest start/stop controls; persist only stop preference, never foreground coordinates. Stop remains effective across lifecycle events and reload, until explicit enable.

Lifecycle: visibilitychange and pageshow resume after rechecking granted permission; clear watch while hidden, cancel stale permission results/callbacks, no duplicate watchers, no new polling. Unknown Permissions support needs a user gesture, never a speculative prompt. Use lower power location settings outside navigation; preserve existing accurate navigation settings and bounded stall recovery, suppress stall rearming while hidden/stopped. No background iOS guarantee, physical iPhone or PWA suspension validation claimed from desktop emulation.

Tests: mock permission granted/prompt/denied/unsupported, lifecycle races, stop during pending permission, late callbacks, observer cleanup, watcher ownership across navigation and rearm, denied/unavailable/timeout, local storage unavailable and persisted opt-out. Real Chrome at iPhone sizes with simulated GPS: launch auto grant, no prompt, first center, exploration before/after fix, recenter, explicit stop/reload/resume, navigation fix/voice/reroute regressions. Run relevant unit/integration tests, TypeScript, lint, build and Linux PR CI. Retain existing recorded route fixtures, no live route/provider requests in new browser tests.

Release: all required automated checks pass and PR contains concise evidence and known iOS limits. Do not deploy without explicit approval; this overrides repository default production-release completion rules for this request.
